Background & Scope

Problem Statement & Project Objectives

Challenges
Traditional Diagnosis Bottlenecks
  • Delayed Diagnosis: Often occurs around 4–5 years of age, causing children to miss the crucial early intervention window.
  • High Cost & Waiting Lists: Requires multiple lengthy specialist evaluations with limited developmental specialists available.
  • Subjectivity: Based on behavioral observations which can vary significantly from one clinician to another.
Goals
Project Objectives
  • 01. ASD Classification: Accurately classify subjects as ASD or Non-ASD using eye-tracking scanpath data.
  • 02. CNN Feature Extraction: Extract meaningful visual gaze representations using MobileNet.
  • 03. Dimensionality Reduction: Apply PCA to reduce features to 250 components, eliminating noise.
  • 04. Ensemble Learning: Maximize accuracy using Stacking (SVM + KNN → Logistic Regression).
  • 05. Clinical Web Portal: Deliver an interactive app with clear visual explanations.
Data Foundation

Dataset Description & Preprocessing Pipeline

ETSDS Eye Tracking Dataset
  • Data Modality: Eye-tracking scanpaths recorded using high-speed eye-tracking devices showing where attention goes.
  • Classes: 219 ASD images and 328 Non-ASD images (Total: ~547 raw samples).
  • Train-Test Split: Stratified 80% Training / 20% Testing split to preserve class ratios.
  • Augmentation: Rotation (±15°) and mirroring expanded training data to ~1,750 images, reducing overfitting.
Preprocessing Steps
  • 1. Resize: Standardized to 224×224 pixels (CNN standard).
  • 2. Gaussian Blur (5×5): Light smoothing to remove jagged line artifacts.
  • 3. RGB Conversion: Consistent 3-channel color format across all samples.
  • 4. Normalization: Pixel values scaled to [0, 1] for stable gradient flow.
  • 5. Color Gradient Preservation: Preserves gaze heatmap intensity gradients.
Feature Engineering

Feature Extraction (CNN) & PCA Reduction

MobileNet vs. ResNet50
  • MobileNet Architecture: Uses Depthwise Separable Convolutions (~4 Million parameters) vs ResNet50 (~25 Million parameters).
  • Higher Accuracy: MobileNet achieved 92.69% accuracy vs. ResNet50's 90.12%.
  • Computationally Efficient: 6x smaller model size, runs significantly faster on clinical web and edge devices.
  • Preferred Model: MobileNet delivered the best speed-to-accuracy tradeoff.
PCA — Dimensionality Reduction
  • Target Components: Reduced thousands of raw features down to 250 Principal Components.
  • Variance Retained: Preserves ~95% of total variance while eliminating redundant noise.
  • Prevents Overfitting: Balances information retention with high generalization capability.
  • Cutoff Efficiency: Lowers memory and compute requirements for real-time web screening.
Ensemble Learning

Stacking Ensemble Model Architecture

BASE MODEL 1
Support Vector Machine
RBF Kernel
  • Constructs non-linear decision boundaries in high-dimensional feature space.
  • Highly robust to PCA-reduced inputs.
  • Learns global boundary margins between classes.
BASE MODEL 2
K-Nearest Neighbors
k = 5 Neighbors
  • Instance-based lazy learner capturing local geometric density.
  • Optimized at k=5 neighbors.
  • Complements SVM by detecting localized point clusters.
META MODEL
Logistic Regression
Probability Calibration
  • Trained on SVM and KNN predictions using 5-fold cross-validation.
  • Learns optimal weighting to correct individual model mistakes.
  • Outputs calibrated probability scores.

Key Findings
Key Observations from Data
  • Stacking Performed Best: Combining SVM + KNN gave a +5.35% boost over SVM alone and +8.48% over KNN alone.
  • PCA Vastly Improved Performance: Jumped from 78.56% to 92.69% by removing noise and collinearity.
  • MobileNet Speed-Accuracy Tradeoff: Outperformed ResNet50 while running 4x faster with fewer parameters.
  • Eye-Tracking Reliability: Confirmed as a reliable, non-invasive digital biomarker for ASD screening.

Explainable AI (Simple Words)

Explainability: Why Did the AI Make This Decision?

CHECK 1
Where Did They Look?
Peripheral vs. Center

Children with Autism often fixate on the outer borders or empty background rather than looking across the whole scene. Our system measures if their gaze is clustered away from central objects.

CHECK 2
Eye Contact & Faces
Face Avoidance (<30% Dwell)

When shown images of people, neurotypical children naturally look at eyes and mouths (~68% dwell). In ASD scanpaths, this drops below 30%, showing clear avoidance of social facial cues.

CHECK 3
Smooth vs. Jerky Jumps
Restless Eye Movements

Instead of following calm, smooth lines between objects, children with Autism often make short, scattered, zigzag eye movements. The system flags this high path jitter as a key indicator.

Handbook & User Guide

System Handbook: Instructions for Users & Clinic Staff

File Formats
What Images Can Be Uploaded?
  • Supports standard PNG, JPG, and JPEG files.
  • Compatible with raw gaze plots, line scanpaths, and colored heatmaps.
  • Any resolution works—the server automatically standardizes sizing to 224×224.
Reliability
Built-In Safety & Fallback
  • If trained model files are not installed, the app NEVER crashes.
  • It automatically runs in "simulation mode" using contour analysis to allow offline demonstrations.
  • A clear banner informs the doctor whether live weights or simulation mode is active.
Responsibility
Screening Aid vs Final Diagnosis
  • The portal explicitly states it is a screening assistant, not a replacement for a doctor.
  • Provides a confidence score so clinicians can see if a result is borderline or strong.
  • Recommends formal ADOS-2 clinical testing when a high-risk pattern is detected.
